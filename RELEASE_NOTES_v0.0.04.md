# 🚀 OsthirKeyboard v0.0.04 — Custom Layout Editor, Tasker Automation & Settings Polish

Welcome to **OsthirKeyboard v0.0.04**! This release introduces a powerful **Custom Key & Layout Editor**, deep **Tasker & Automation integration**, an overhauled and intuitive **Settings hierarchy**, and enhanced preference visuals and icons.

---

### 🌟 Key Highlights

- **🎹 Visual Custom Layout Editor**: Customize individual keys, tap actions, and 8-direction swipe shortcuts with live keyboard preview.
- **⚡ Tasker & Automation Integration**: Trigger Tasker tasks directly from key swipes and taps with built-in task discovery and helper builders.
- **📂 Overhauled Settings Architecture**: Grouped and streamlined preferences into clear categories (Typing, Style, Layout, Suggestions, Tools, and Automation).
- **🎨 Distinct Vector Iconography**: Added custom vector icons for opacity controls, gestures, and quick tools.
- **🖼️ Custom Theme Preview Polish**: Elevated card backings ensuring full wallpaper visibility and contrast in light and dark modes.

---

### ✨ What's New & Improvements

#### 🎹 Custom Layout Editor
- **Live Key Customizer (`LayoutEditorActivity`)**: Select any key on the keyboard to modify primary characters, shift actions, and multi-directional swipe shortcuts.
- **Custom Theme Wallpaper Support**: Layout Editor now renders custom theme wallpapers with proper card contrast for effortless editing under any theme.

#### ⚡ Tasker & Automation
- **Direct Tasker Actions**: Bind any key tap or swipe direction to execute Tasker automation profiles.
- **Tasker Automation Builder**: Intuitive configuration preference to select and test tasks seamlessly.

#### ⚙️ Settings Restructuring & Visuals
- **Structured Categories**: Reorganized preferences into logical categories with unified headers and spacing.
- **Distinct Opacity & Gesture Icons**: Created dedicated icons for Keyboard Opacity, Key Opacity, Pressed Key Opacity, and Gestures.
- **Preference Dialog Padding**: Fixed edge padding issues on text/dialog preferences (e.g. Giphy API Key).

---

### 📦 Installation

1. Download **`OsthirKeyboard.apk`** from the Assets below.
2. Open the file on your Android device to install or update.
3. Your custom settings, themes, and learned dictionaries will be preserved.
